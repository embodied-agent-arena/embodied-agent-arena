Evaluation Details

Metrics & Scoring

Rotation and translation measure pose error; AbsRel measures numerical spatial error. Box–mask IoU and Polygon IoU score region overlap on the same 70 Affordance cases using separate box and polygon outputs. Planning covers 157 cases; Manipulation covers 182 binary assignments, plus one continuous-reward case in the inventory. Failed and missing outcomes count as unsuccessful.

Protocol & Budgets

All agents use RGB and source-native tools. In Manipulation, the original eight use the native Baseline image schedule; DeepSeek-1017 receives current RGB at each decision, with the same listed per-source round, token, and in-episode time ceilings. RoboCasa allows 60 minutes and 24 model rounds; BEHAVIOR-1K allows 180 minutes and 24 rounds.

Polygon grounding, tracing, Planning, and Manipulation use one run per assignment. Repeated probes use five runs, except Fable (three). Full repetition settings ↗
