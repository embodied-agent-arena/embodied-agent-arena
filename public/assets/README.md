# Project page assets

Research figures and case-study previews accompany the Embodied Agent Arena paper. `logo.png` is the project logo. The interactive page selects these figures in `../app.js`.

The paper in `../paper.pdf` contains the complete vector research figures and their captions.

`huggingface-logo.svg` is the official Hugging Face logo, sourced from [Hugging Face](https://huggingface.co/front/assets/huggingface_logo-noborder.svg). A matching viewBox enables responsive sizing without changing the artwork. It identifies the paper and dataset links.
