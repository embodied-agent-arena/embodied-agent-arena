Which Frontier VLM Performs Best on Robot Tasks?

GPT-6 Astra leads Task Planning (80.3%) and rotation estimation. Gemini 4 Argon leads Spatial Pass@1 (71.6%) and region overlap (0.356 box–mask IoU; 0.441 polygon IoU). Claude Opus 5.5 has the highest reported Manipulation success (47.8%). Even the strongest Manipulation score leaves more than half of the assigned tasks incomplete. Table 2.

Strengths differ across domains. Gemini 3.8 Flash has the lowest numerical Spatial Reasoning error (AbsRel 0.161); Qwen 3.8 Max nearly matches Astra on Spatial Pass@1 (68.9% versus 69.4%). DeepSeek 4.1 Flash-1017 reaches 51.6% Spatial Pass@1, 31.2% Planning, and 20.9% Manipulation, with substantial differences across sources. Full ten-model comparison.

GPT-6 Sol reaches 44.6% Planning and 19.8% Manipulation; Fable 5.1 reaches 63.7% and 24.7%. Qwen 3.5 397B-A17B outperforms Qwen 3.5 27B on Spatial Pass@1 (50.6% versus 48.0%), while the smaller model has higher Manipulation success (11.0% versus 9.9%). Capability profiles.

Why Can Precise Local Actions Still Leave Tasks Unfinished?

Geometric estimates, contact points, and near-correct trajectories describe intermediate competence. Complete tasks also require the right endpoint, ordered subgoals, and the final environment state—all within a finite budget. Geometric and spatial diagnostics.

All ten agents complete 0/5 BEHAVIOR-1K tasks under ceilings of 180 minutes per trial, 24 model rounds, 256 tool calls, 640k tokens, and 1,000 control steps. All ten also complete 0/8 HumanCLAW sitting tasks, with 180 minutes, 101 code rounds, 100 environment steps, 400 primitive calls, and 2M tokens (11,000-second outer timeout). Runs can end without success before the time limit. Opus 5.5 completes 3/13 HumanCLAW tasks and DeepSeek-1017 2/13; their successes are navigation tasks. Gemini 4 Argon also completes 2/13 HumanCLAW tasks, both navigation. Planning and Manipulation results.

The evaluation therefore separates local accuracy from complete-task success. A minimal harness leaves interpretation, reasoning, and action selection to the model. Execution traces separate restarting code from completing a task: 62 of 65 CALVIN episodes with execution errors later run code without an error, but only three subsequently complete all five goals. The fixed-input review study similarly separates improvement in an intermediate score from satisfying a success criterion. Feedback and recovery.

How Were the Agents Evaluated?

Shared evaluation framework. All ten models use the same task inventory, source-native interfaces, RGB observations and native success criteria. Manipulation retains the observation schedule and resource limits of each recorded batch.

Recorded execution settings. All ten retained Astra CALVIN episodes use 20 rounds, 640k total tokens and 60 minutes. The corresponding Opus 5.5, DeepSeek-1017 and Gemini 4 Argon reports use 40 rounds, 1.28M tokens and 120 minutes with automatic RGB feedback. Verified reports and configuration audit ↗

Repetitions. Non-tracing Geometry uses five runs, except Fable (three). Spatial Reasoning and box/point Affordance use five, except Fable (three). All ten agents use one run per assignment for polygon grounding, tracing, Planning, and Manipulation. Repeated metrics report the mean and sample SD across runs. Each run averages valid continuous estimates; success rates retain failed and missing assignments. Scoring and repetition accounting.

Task sets. Planning covers all 157 cases, including HumanCLAW: Opus 5.5 completes 76/157 (48.4%), DeepSeek-1017 49/157 (31.2%), and Gemini 4 Argon 110/157 (70.1%). Manipulation counts 182 binary assignments; Opus 5.5 completes 87 (47.8%), DeepSeek-1017 38 (20.9%), and Gemini 4 Argon 80 (44.0%). The 183-case inventory also includes one continuous-reward task. Box–mask and polygon IoU use the same 70 Affordance cases under separate output protocols. Invalid or absent polygons receive zero. Polygon grounding.
