# Model identification marks

These marks identify the evaluated model families. They do not indicate sponsorship or endorsement.
The Claude Spark comes from Anthropic's official press kit. Other SVG marks come from the Lobe Icons
collection; exact source URLs and checksums are in `sources.json`, with its license alongside.
Brand names and marks remain the property of their respective owners.

Each mark is a separate embedded SVG object in draw.io. Model labels remain editable text.
PDF exports preserve vector paths and gradients. SVG exports preserve the source logo paths and gradients.
Full model versions are documented in the manuscript's model-configuration table.
