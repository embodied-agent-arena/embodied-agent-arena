Evidence and Timing

Each trace identifies its source record and report SHA-256. The 711 recorded rounds retain their elapsed time, executed code excerpts, feedback and 6,972 primitive calls from the Manipulation traces. Planning exposes saved code-cell feedback and environment-step counts. Tool calls, model responses and environment steps are distinct units.

Video excerpts and saved observations have their own playback clock. They are not linearly stretched to episode wall time. Total duration includes setup where the report records it; round timestamps start at the agent loop. Input and output tokens are included, and missing billing data is not reported as zero cost.

These selected episodes explain behavior, rather than estimate benchmark-wide rates. See the full benchmark comparison for aggregate results, and download the episode metrics.
